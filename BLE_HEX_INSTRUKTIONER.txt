BLE HEX INSTRUCTIONS (Felix Home)
==================================

IMPORTANT
---------
- BLE commands are sent as RAW BYTES (hex), not text.
- Characteristic: service 0xFFF0, write characteristic 0xFFF1.
- Byte 0 = lamp_id
- Byte 1 = cmd

Format
------
[ lamp_id ][ cmd ][ optional data ... ]

Supported commands
------------------
1) OFF
   cmd = 0x00
   Length = 2 bytes
   Example:
   - Lamp 1 OFF: 01 00

2) ON
   cmd = 0x01
   Length = 2 bytes
   Example:
   - Lamp 1 ON: 01 01

3) BRIGHTNESS
   cmd = 0x02
   Length = 3 bytes
   Byte 2 = level (0..255)
   Example:
   - Lamp 1 brightness 128: 01 02 80

4) COLOR RGB
   cmd = 0x03
   Length = 5 bytes
   Byte 2 = R, Byte 3 = G, Byte 4 = B (0..255)
   Example:
   - Lamp 1 red:   01 03 FF 00 00
   - Lamp 1 green: 01 03 00 FF 00

Lamp ID
-------
- lamp_id = 0x01 -> Lamp 1
- Only one lamp is supported currently: lamp_id 0x01

Troubleshooting
---------------
- If you see "not marked as joined" in the log:
  the lamp has not joined the Zigbee network yet.
- Check that the lamp is in pairing mode and that nodes log "device joined".

Quick test sequence
-------------------
1) Turn lamp 1 on:         01 01
2) Set brightness 50%:     01 02 80
3) Set warm color:         01 03 FF A0 40
4) Turn lamp 1 off:        01 00

Tips for BLE apps (e.g. nRF Connect)
-----------------------------------
- Use Write / Write Without Response for 0xFFF1.
- Enter payload as HEX bytes (not an ASCII string).
